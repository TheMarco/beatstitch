Beatstitch free-release license review — 2026-10-13

Outcome
-------
The original application code is now GPL-3.0-or-later, as authorized by the
creator. Free access with voluntary Ko-fi support is compatible with GPL.
This does not relicense third-party weights, artwork, fonts, or libraries.
The Mac release is being staged locally with a matching source companion.
MuQ donation-related interpretation remains a creator-accepted uncertainty.

Evidence scope
--------------
Reviewed the installed Mac bundle, its 100-entry pre-change credits catalog,
the pinned model manifests/downloaders, published licenses, publisher model
metadata and licensing statements. The current production source catalog has 105 entries including BeatStitch;
Demucs-only dependencies are removed and all listed entries have offline notices. Small public API responses are retained under
outputs/license-review. The initial evidence review did not download weights;
the subsequent Spleeter implementation downloaded the official licensed archive.
This is a technical evidence review, not a warranty about third-party rights,
patents, all possible uses, or every future Windows/Linux package.

Binary distribution requirements
-------------------------------
GPL/Open-source licensing solves the proprietary-code issue for our audio
engines; it does not remove corresponding-source obligations.

- FFmpeg/ffprobe in the Mac bundle: 9.0.2, --enable-gpl and --enable-version3,
  linked to x264/x265. Keep GPL-compatible distribution and provide the exact
  corresponding source, patches and build instructions for FFmpeg and covered
  linked components. The separate companion source archive contains this
  source set, original formulae and configure records. Do not replace the existing binary just for licensing
  without rechecking audio/cache compatibility.
- Rubber Band 4.0.0: GPL-2.0-or-later. A GPL-compatible application release can
  use the open-source edition; a proprietary license purchase is not our
  planned route. Package the exact source/build material and notices.
- Qt/PySide6: original GPL/LGPL terms apply per component. The Mac Cocoa repair
  already includes the matching qtbase source archive, patch and rebuild recipe
  in Contents/Resources/qt-cocoa-fix. This covers that source package, not every
  additional Qt module, Python binding or multimedia backend.
- Qt playback FFmpeg is separate from command-line FFmpeg. Identify that build
  and provide its required notices and corresponding sources separately.
- Additional LGPL libraries include soxr and relevant native audio libraries;
  the section edition also uses easydict and frozendict. Demucs-only lameenc is no longer a production dependency. Include their
  required source/notice material. The formerly missing PySide6/Shiboken notices
  are now included from their matching official source release.
- Publish the matching original app source and scripts next to each binary
  release. A link to a moving main branch or an About credits list alone does
  not establish availability of the complete corresponding source.
- Preserve users' rights to replace/rebuild covered libraries. Provide build
  and installation/signing instructions; do not impose conflicting EULA terms.
